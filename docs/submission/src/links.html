3. Cloud deployment with demonstration

Live applicationhttps://parchi-theta.vercel.app
CloudAmazon Web Services, AWS Academy account, region us-east-1, CloudFormation stack parchi-dev (~45 resources)
Services usedAPI Gateway, Lambda (3 API functions + 1 container-image worker), S3, SQS + dead-letter queue, DynamoDB, SNS, ECR, CloudFront, CloudWatch, IAM, AWS SAM / CloudFormation
OCROpen-source Tesseract inside the Lambda worker's Docker image (Amazon Textract is blocked in AWS Academy)
Deploy commandscripts/academy-up.sh: builds and deploys the whole stack, points the website at it and checks it (about 10 minutes)
Measured on AWSUpload → filed in 4.6 – 7.3 s per bill; about 15 s on a cold start
The AWS Academy sandbox deletes all resources when a lab session ends, so the live link works while the lab is running. It is rebuilt with one command before the demonstration.

Demonstration steps

  1. Open the live link; the top-right badge shows dev · us-east-1 · tesseract.
  2. Click a sample bill (e.g. "Pharmacy bill (photo)") and watch the live pipeline: API Gateway → S3 → SQS → Lambda → Tesseract → DynamoDB → SNS.
  3. Open the filed bill: extracted fields with confidence, classification, checks (subtotal + tax = total), line items and the per-service timeline.
  4. Settings: subscribe an email to receive SNS confirmations; "How it works" shows the architecture.
  5. AWS console: CloudFormation stack, Lambda functions (worker package type: Image), CloudWatch dashboard parchi-dev-us-east-1.
